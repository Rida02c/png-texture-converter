# PNG Texture Converter

Batch convert 4K/8K PBR PNG textures to TIFF or JPG for Cinema 4D.

- Smart mode: keeps 16-bit for normal/height/displacement, 8-bit for the rest (~80% smaller, no visible loss)
- Replace originals or save to a separate folder
- Adjustable CPU cores

## Download
Click **PNG-Converter.zip** above, then the download button.

## Use
1. Unzip (if Windows blocks it: right-click zip > Properties > Unblock)
2. Double-click `PNG-Converter.bat`
3. Needs ImageMagick (free) - the tool offers to install it on first run

Windows only. Uses [ImageMagick](https://imagemagick.org).
